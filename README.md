# 贺年卡盲盒

AI 生成的新年贺卡盲盒，点击红包抽取专属贺年卡。

## 功能

- 🧧 **红包盲盒**：点击红包，AI 生成专属贺年卡
- ✨ **开盒动画**：粒子汇聚、红包打开、礼花喷发
- 💾 **一键保存**：长按图片保存到相册

## 快速开始

```bash
# 后端
cd backend
cp env-example.txt .env  # 配置 AI 接口
pip install -r requirements.txt
python run.py

# 前端
cd frontend
npm install
npm run dev
```

访问 http://localhost:5173
